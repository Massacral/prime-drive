# 🚗 Prime Drive — Plataforma de Mobilidade Urbana

### Sistema Full Stack | React • Node.js • TiDB

O **Prime Drive** é uma plataforma de mobilidade urbana desenvolvida para conectar passageiros e motoristas por meio de uma aplicação moderna, intuitiva e responsiva.

O projeto foi desenvolvido de forma independente, abrangendo frontend, backend, banco de dados e regras de negócio.

## 🎯 Objetivo

Criar uma solução de transporte por aplicativo com gerenciamento de corridas, interfaces específicas para passageiros e motoristas e estrutura preparada para integração de pagamentos digitais.

## 🚀 Funcionalidades

- 👤 Cadastro e autenticação de usuários
- 🚘 Interface exclusiva para motoristas
- 📱 Interface exclusiva para passageiros
- 📍 Solicitação e gerenciamento de corridas
- 🔄 Comunicação entre frontend e backend
- 💳 Integração de pagamentos via Pix e cartão em desenvolvimento
- 📊 Estrutura para gerenciamento de comissões
- 🌐 Aplicação web responsiva com suporte a PWA

## 🛠️ Tecnologias utilizadas

**Frontend**
- React
- JavaScript
- HTML5 e CSS3

**Backend**
- Node.js
- API REST

**Banco de dados**
- TiDB (compatível com MySQL)

**Infraestrutura**
- Render
- Git e GitHub
